# AWS Linux Server Project 🚀

## 📌 Overview
This project demonstrates how to launch and manage a Linux server on AWS EC2.

## 🔧 Steps Performed
- Created AWS account
- Launched EC2 instance (Ubuntu)
- Connected using SSH
- Executed basic Linux commands

- Linux (Ubuntu)
- SSH
