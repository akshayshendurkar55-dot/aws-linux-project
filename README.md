# AWS Linux Server Project

## Overview

This repository documents hands-on practice with AWS EC2 and Ubuntu Linux. It focuses on launching a cloud-based Linux server, connecting to it securely using SSH, and learning essential Linux commands.

The project serves as a foundation for developing practical cloud computing and DevOps skills.

## Objectives

* Understand the basics of AWS EC2.
* Practice working with an Ubuntu Linux server.
* Learn how SSH is used for remote server access.
* Practice essential Linux commands.
* Build a foundation for cloud infrastructure and server administration.

## Tools and Technologies

* **AWS EC2** — Virtual server hosting
* **Ubuntu Linux** — Operating system
* **SSH** — Remote server access
* **Linux CLI** — Command-line administration

## Repository Structure

```text
aws-linux-project/
├── README.md
└── commands.txt
```

* `commands.txt` — Linux commands collected during hands-on practice.
* `README.md` — Project overview, learning objectives, and documentation.

## Learning Areas

* EC2 instance fundamentals
* Connecting to a Linux server through SSH
* Navigating directories and managing files
* Practicing basic Linux commands
* Understanding the role of Linux in cloud and DevOps environments

## Security and Cost Considerations

* Keep private SSH keys secure and never commit them to GitHub.
* Restrict SSH access to trusted IP addresses instead of allowing unrestricted access.
* EC2 instances and associated resources may incur charges depending on their configuration and usage.
* Check AWS billing and clean up resources that are no longer required.

## Current Scope

This repository represents foundational AWS and Linux practice. Advanced automation, monitoring, and production deployment are not claimed as completed features.
